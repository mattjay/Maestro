# iOS Development Video Tutorial Scripts

This directory contains production-ready scripts for the iOS development tutorial video series.

| # | Title | Duration | Script |
|---|-------|----------|--------|
| 1 | Getting Started with iOS in Maestro | 5 min | [01-getting-started.md](./01-getting-started.md) |

**Total Series Duration**: ~33 minutes

## Script Format

Each script follows a consistent format:

1. **Header**: Title, duration, target audience, objective
2. **Pre-Production Notes**: Required footage checklist, assets needed
3. **Script Body**: Timestamped sections with:
   - Visual cues in `[VISUAL: ...]` format
   - Narrator dialogue
   - Code examples and command outputs
4. **Post-Production Notes**: Timing breakdown, visual effects, supplementary materials

## Intended Learning Path

1. **Getting Started** - Environment setup, first snapshot, basic inspect
2. **Automating UI Tests** - Flow creation, playbooks, error handling
3. **Visual Regression** - Baselines, diffs, thresholds, ignore regions
4. **MaestroBridge** - State inspection, feature flags, network, analytics

Each video builds on the previous, creating a comprehensive learning experience.

## Production Guidelines

### Visual Style
- Consistent Maestro branding (logo, colors)
- Clean macOS desktop with minimal distractions
- iOS Simulator prominently displayed
- Code shown in syntax-highlighted editor

### Audio
- Professional voiceover narration
- Optional: keyboard/click sound effects during demonstrations
- Background music (subtle, non-distracting)

### Captions/Overlays
- Commands displayed in large, readable font when typed
- Important output sections highlighted with circles/arrows
- Timestamps shown for file paths and durations

### B-Roll Suggestions
- Keyboard typing close-ups
- Simulator device animations
- Split-screen showing Maestro + Simulator
- Progress indicator animations

## Supplementary Materials

Each video should link to:
- Relevant documentation pages
- Sample code downloads
- Quick reference cards
- Related videos in the series
